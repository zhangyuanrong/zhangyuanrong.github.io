# 一、缘起

在学习金融资产章节，有一个典型的分录：

```
借：交易性金融资产-公允价值变动损益
贷：公允价值变动损益
```

当时还不明白这个分录是什么意思，只能硬记。

第一，先搞清两个会计科目属于哪一类要素：

交易性金融资产是资产类科目（公允价值变动损益是二级明细），公允价值变动损益是损益类科目。

第二，结合会计恒等式理解：

```
资产↑+成本Δ+费用Δ=负债Δ+所有者权益Δ+收入↑
```

左边和右边同增，等式成立。



# 二、分析

从会计恒等式可以看出，资产、成本、费用的变动方向一致，与负债、所有者权益、收入的变动方向相反；各要素科目与其备抵科目（如有）的变动方向相反。

通常的解释是根据资金运动的方向来划分会计要素的变动方向：

等式左侧是资金流出，表示钱花在哪里，会计科目的变动方向是借增贷减；

等式右侧是资金流入，表示钱从哪里来，会计科目的变动方向是借减贷增。

但是，对于一些特殊的交易或事项，资金运动论未必成立。

例如，接收无偿划入资产，资产增加不一定就会导致资金流出。

```
借：长期股权投资等
贷：资本公积等
```
```
资产↑+成本Δ+费用Δ=负债Δ+所有者权益↑+收入Δ
```

同理，赊销货物最终没有取得款项，收入增加不一定就会导致资金流入。

```
借：应收账款
贷：主营业务收入
```
```
资产↑+成本Δ+费用Δ=负债Δ+所有者权益Δ+收入↑
```

总之，会计分录各科目引起的变动必须保证会计恒等式成立，无需纠结借贷的意义。
